🚀 Do zero ao Deploy: O meu primeiro grande projeto na tecnologia!

Comecei minha faculdade de Gestão da Tecnologia da Informação em fevereiro de 2026 e, desde então, tenho mergulhado de cabeça na prática. Hoje, tenho muito orgulho de apresentar o resultado desse aprendizado contínuo: o Matemática Divertida!

Esse é o meu primeiro projeto completo, construído do planejamento ao deploy. Não é apenas um app de estudos, mas um sistema robusto que envolve:

🧠 Gamificação e Lógica: Modos de jogo dinâmicos e ranking global em tempo real.
🛠️ Arquitetura Moderna: Desenvolvido em Flutter e Firebase, garantindo segurança (autenticação) e persistência de dados.
🧪 Qualidade de Software: Suíte completa de testes unitários automatizados.
🌐 Internacionalização (i18n): Suporte nativo a múltiplos idiomas (pt_BR / en).

O mais legal dessa jornada? Construir tudo isso contando com o apoio de inteligência artificial para acelerar meu aprendizado, debugar códigos complexos e aprimorar a experiência do usuário (UX). Entendi que a IA não substitui o desenvolvedor, mas potencializa quem sabe usá-la como copiloto.

O app já está rodando na web e aberto no GitHub para quem quiser conferir o código-fonte!

🔗 Jogue direto no navegador: https://matematica-divertida-b285a.web.app
💻 Repositório no GitHub: https://github.com/Irivania/matematicadivertida

Entre na pasta do projeto:

Bash
cd matematicadivertida
Instale as dependências:

Bash
flutter pub get
Execute o aplicativo:

Bash
flutter run
🧪 Executando os Testes
Para rodar a suíte de testes unitários automatizados:

Bash
flutter test
